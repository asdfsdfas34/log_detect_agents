### 프로젝트 명

Mini-AIOps

### 배경 및 문제 정의

* 현재 상황 (As-Is): 반복업무 수행, 운영자 개인이 eye check 하는 방식으로 자동화 필요

* Pain Point: 매 배포주 익일 15분, 매달 1시간여 사용하여 시스템 로그 상세 점검 진행

* 기회 요인: 반복적 업무, 패턴화된 데이터로 특이값 검증 자동화 가능

### 목표 사용자 (Target User)

시스템 운영자, 주기적 시스템 점검을 통한 유지보수 및 품질 향상 업무 수행

### 프로젝트 목표

* 정성적 목표

  * 목표 1: 반복업무 자동화

  * 목표 2: 오류 부분 사전 탐지

  * 목표 3: 원인 분석 표준화

  * 목표 4: 지식 축적 및 운영 품질 향상

* 정량적 목표 (KPI)

|                            |           |                        |           |
| -------------------------- | --------- | ---------------------- | --------- |
| **성과 지표**                  | **목표 수치** | **측정 방법**              | **현재 수준** |
| 주간 배포 후 로그 점검 시간 감소        | 5분        | Agent를 통한 로그 점검 결과 확인  | 15분 소요    |
| 월간 전체 시스템 로그 상세점검 소요 시간 감소 | 10분       | Agent 를 통한 로그 점검 결과 확인 | 40분 소요    |
| 이상 데이터 감지율                 | 80%이상     | 이상 데이터 감지율 80%이상       | -         |

### 핵심 기능 정의

### ① 로그 수집 (Log Collector)

* 시스템별 정규화 된 로그 수집

* 로그 타입, 메시지, 상세 메시지, 발생 위치, 발생 시각 저장

* 로그 Fingerprint(ex.FP-000123 등 개별 코드값) 생성 및 중복 로그 집계

### ② 로그 분석 (Log Analysis)

* 로그 유형별 분류 및 저장

* Known Pattern Registry 기반 기등록 장애 패턴 탐지

* 신규 패턴 자동 식별

* 규칙(Rule) + confidence score 기반 분석 수행

### ③ 이상 탐지 (Anomaly Detection)

* 오류 발생량 급증 탐지

* 신규 예외 발생 탐지

* 비정상 패턴 분석

* 로그 미발생(Silence) 탐지

### ④ 해결방안 추천 (Recommendation)

* RAG 기반 사례 검색(메모리카드 기존이력)

* RAG + LLM 기반 해결방안 생성

* 근거(Evidence) 중심의 추천 결과 제공

* 추천 결과 및 검증된 사례를 지식 DB로 축적

### ⑤사용자 검증 및 학습

* 감지 결과 예외 등록 기능

* AI 분석 결과 승인/반려 기능 - 결과 DB적재 여부 검토

  * 사용자 피드백 기반 지속적 성능 개선

  * 메모리(등록데이터) 카드 등록 , 조회 기능

  * 예외처리 등록, 조회 기능

### 기대 효과

* 업무 효율화: 점검 처리시간 60%이상 단축

* 품질 향상: 이상감지 및 선제적 조치로 서비스 운영 안정성 확보, 개선작업을 통한 품질 향상

* 비용 절감: 인력투입 70%감소 - 모든 운영자 점검 => 대표운영자 점검

### 범위 및 제약사항

* In Scope: 로그 적재/분류, 이상 탐지, 위험여부 안내

* Out of Scope: 파일 형식의 로그 raw 데이터 자동 분류 처리

* 제약사항: 로그 수집 대상 시스템에서 약속된 로그 형식의 데이터를 전송 해야 함.

  * 예시

```json
{
  "service_name":"board-service",
  "log_level":"ERROR",
  "message":"개체 참조가 개체의 인스턴스로 설정되지 않았습니다.",
  "stacktrace":"System.NullReferenceException at BoardService.GetPost(1)",
  "source":"BoardService.cs",
  "created_at":"2026-06-12 10:00:00"
}
```
